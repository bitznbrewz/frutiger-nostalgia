# Changelog

## 1.0.0

- Initial release with two themes: **Aero Glass** (dark) and **Aero Sky** (light).
- Full workbench coverage: title bar, activity bar, tabs, lists, widgets, terminal ANSI colors, diff, git decorations and bracket pairs.
- TextMate and semantic token colors tuned for at least 4.5:1 contrast on the editor background.
