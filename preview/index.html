Install

After installing, open the Command Palette, run Preferences: Color Theme, and choose Aero Glass or Aero Sky.

Package a VSIX

Build an installable file from the repository, then install it.

git clone https://github.com/bitznbrewz/frutiger-nostalgia
cd frutiger-nostalgia
npx @vscode/vsce package
code --install-extension frutiger-nostalgia-1.0.0.vsix

Link the folder

Symlink the repository into your extensions folder, then reload VS Code.

# macOS / Linux
ln -s "$PWD/frutiger-nostalgia" \
  ~/.vscode/extensions/frutiger-nostalgia
